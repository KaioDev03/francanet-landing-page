# 🌐 FrancaNet — Landing Page

Landing page institucional desenvolvida para o provedor **FrancaNet Telecomunicações**, com foco em conversão, clareza das informações e performance.

O projeto foi pensado para ser simples, moderno, responsivo e otimizado para captação de clientes via WhatsApp.

---

## ✨ Visão Geral

Esta landing page apresenta:

* Proposta de valor clara já no Hero
* Seção institucional explicando o diferencial da empresa
* Planos de internet destacados
* CTA direto para WhatsApp
* Layout responsivo para desktop e mobile
* Animações suaves para melhor experiência do usuário

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **Tailwind CSS** (via CDN)
* **JavaScript**
* **AOS (Animate On Scroll)** para animações
* **SVG Icons** para melhor performance visual

---

## 📱 Responsividade

O site é totalmente responsivo, adaptando-se corretamente para:

* Smartphones
* Tablets
* Notebooks
* Monitores Full HD

---

## 🚀 Funcionalidades

* Navegação suave entre seções
* Botões de CTA com foco em conversão
* Redirecionamento direto para WhatsApp
* Destaque visual para plano principal
* Footer institucional com CNPJ
